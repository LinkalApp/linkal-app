### Tecnologías necesarias

`Java` `Gradle` `GitHub` `GitHub Actions` `GitHub Packages`

### :gear: Instalación del proyecto

1. Clonar el repositorio en tu equipo, **mediante consola**:

```sh
> cd <folder path>
> git clone https://github.com/LinkalApp/linkal-app.git
```

2. Importar el proyecto mediante **Android Studio**
    * **Open**, y seleccionar la carpeta del proyecto.

### :gear: Ejecución en local con Android Studio

1. Seleccionar la variante de compilación **debug** desde `Build Variants`.
2. Iniciar un emulador Android desde **Device Manager**.
3. Pulsar el botón **Run**.
